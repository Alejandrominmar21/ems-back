# Employee Management System (EMS) - Backend
API RESTful básica construida como proyecto de consolidación en el ecosistema Spring Boot, diseñada siguiendo las buenas prácticas de arquitectura modular y limpia.

## Características
- Operaciones CRUD: Endpoints para crear, consultar, actualizar y eliminar registros de empleados.

- Diseño por capas: Separación clara de responsabilidades entre controladores REST, lógica de negocio y acceso a datos.

- Patrón DTO & Mapper: Aislamiento del modelo de base de datos de la capa de exposición web mediante DTOs y mappers dedicados.

- Manejo de errores: Gestión personalizada de excepciones para recursos no encontrados (ResourceNotFoundException).

## Stack Tecnológico
- Lenguaje: Java

- Framework: Spring Boot (Spring Web, Spring Data JPA)

- Persistencia: Hibernate / JPA

- Gestor de dependencias: Maven
